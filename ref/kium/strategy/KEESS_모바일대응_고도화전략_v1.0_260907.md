## 3. 전략 원칙

### 원칙 1. 손가락을 1급 입력으로 취급한다

마우스 기준으로 만든 규칙이 터치에서 부작용을 낸 것이 M2·M4·M7의 공통 원인입니다.

- hover는 **hover 가능한 기기에서만** 선언 (`@media (hover:hover) and (pointer:fine)`)
- 터치 타깃은 시각 크기와 분리: **보이는 크기는 유지하고 히트 영역만 44px로 확장**(가상 요소 또는 패딩)
- 제스처 경계는 명시적으로 차단 (`overscroll-behavior`)

### 원칙 2. 단말 브라우저의 실제 동작에 맞춘다

명세서상 정상이어도 iOS/Android 브라우저가 개입하는 지점이 있습니다.

- 입력 폰트 **16px 하한**은 디자인 선택이 아니라 iOS 제약
- 뷰포트 높이는 `dvh` 기준 (주소창 가변)
- 모달·시트는 배경 스크롤을 **잠근다**

### 원칙 3. 이미 있는 최선을 단일 출처로 승격한다

새 패턴을 만들지 않습니다. 저장소 안에 이미 정답이 있습니다.

| 이미 존재하는 최선 | 승격 대상 |
| --- | --- |
| `components.css`의 `100dvh` 처리 | `.hero`, `.kium-sheet` |
| `.subnav-in`의 `overscroll-behavior-x:contain` | 가로 스크롤 컨테이너 전체 |
| `.kium-ustrip`의 `scroll-snap-type` | `.kium-filters` |
| `.kium-filters`의 mask 페이드 | 스트립 계열 |

### 원칙 4. 브레이크포인트는 이번에 정리하지 않는다

M9는 실사용 결함이 아니라 유지보수 부채입니다. 19종을 한 번에 통합하면 **전 페이지 회귀 위험**이 P0 수정과 뒤섞입니다.

- 이번 범위: **신규 선언만 표준 3종(560 / 767 / 880)으로 제한**
- 기존 값 통합: 별도 리팩터링 건으로 분리
